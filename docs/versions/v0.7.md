## ✅ ОСНОВНЫЕ КОМПОНЕНТЫ

### 1. Frontend (SPA архитектура)
- Vanilla JavaScript (без фреймворков)
- CSS3 с темами (light/dark)
- Вкладки: Dashboard, Файлы, Заказы, База Данных

**Функции:**
- ✅ Просмотр файлов в таблице/галерее
- ✅ Фильтрация по расширению и категориям
- ✅ Поиск файлов
- ✅ Управление категориями
- ✅ Просмотр PDF, 3D моделей, изображений

### 2. Backend (Electron Main Process)
- Node.js с IPC коммуникацией
- Безопасный контекст (contextIsolation)
- Асинхронные операции с файлами

**Функции:**
- ✅ Сканирование проектов
- ✅ Индексация файлов с кэшированием
- ✅ Генерация миниатюр
- ✅ Управление категориями

### 3. База Данных
- JSON файл (artel.json)
- Структурированная система проектов
- Автоматические резервные копии

**Структура:**
```json
{
  "projects": { /* проекты */ },
  "files": [ /* все файлы */ ],
  "categories": [ /* категории файлов */ ]
}
```

### 4. Интеграции
- **Telegram Bot** — получение заказов из чата
- **Google Drive** — синхронизация данных проектов

### IPC Архитектура
```
Frontend (app.js)
    ↓ window.api.someFunction()
Preload.js (IPC мост)
    ↓ ipcRenderer.invoke()
Main.js (IPC обработчик)
    ↓ fs, path, операции
Результат обратно в Frontend
```

## 🎓 ОСОБЕННОСТИ РЕАЛИЗАЦИИ

### Портативные пути
```javascript
// Работает на любом компьютере
const ROOT = config.rootPath; // F:\GOOGLE\Артель
const PROJECT = path.join(ROOT, 'Проекты', projectName);
```

### Безопасный IPC
```javascript
// main.js
ipcMain.handle('api:getData', async () => {
  // Защищенная функция, проверка входных данных
  return { projects: [...] };
});

// app.js
const data = await window.api.getData();
```

### Асинхронное загружение
```javascript
// Загружаем данные при старте приложения
async function init() {
  const data = await window.api.getData();
  appState.projects = data.projects;
  renderProjects();
}
```
