📚 Введение в АРТЕЛЬ

АРТЕЛЬ — это современное приложение для управления файлами проектов с красивым интерфейсом и умными функциями.

💼 Управление файлами
Организуйте файлы проектов по категориям, добавляйте метаданные и ищите нужное за секунды
🤖 Telegram интеграция
Получайте заказы прямо из Telegram бота и управляйте ими в приложении
☁️ Google Drive синхронизация
Автоматическая резервная копия ваших проектов в облако

🏗️ Как устроено приложение

📍 АРТЕЛЬ = Electron приложение (Node.js + Vanilla JavaScript + CSS3)

Три слоя приложения:

🎨 Frontend (UI)
Красивый интерфейс на чистом JavaScript и CSS3.
Файлы: index.html, app.js, styles.css
⚙️ Backend (Логика)
Node.js работает в главном процессе Electron.
Файл: main.js
💾 База данных
JSON файл с информацией о проектах и файлах.
Файл: data/artel.json

Синхронизация данных:

GitHub (код) ↔ Google Drive (данные) ↓ ↓ main.js Проекты/ app.js photos/ styles.css backups/
✅ Правило: GitHub хранит код, Google Drive хранит данные пользователя

Как читать версии:

Каждая версия имеет файл vX.X.md в папке docs/versions/. Там описано что изменилось в этой версии и как это соответствует регламенту.

🚀 Как разрабатывать новый патч

1️⃣ Планирование

Прочитайте СТРУКТУРА-АРТЕЛЬ.md — это главный регламент проекта

2️⃣ Проверка

Проверьте что ваши изменения соответствуют СТРУКТУРЕ и не нарушают ЗАПРЕТЫ

3️⃣ Разработка

Разрабатывайте, следуя всем правилам и стандартам из СТРУКТУРЫ-АРТЕЛЬ

4️⃣ Тестирование

Протестируйте в реальном приложении, проверьте функции и ошибки

5️⃣ Коммит

git commit -m "v0.X.X: Краткое описание Подробное описание изменений - Пункт 1 - Пункт 2"

6️⃣ Документирование

Создайте файл docs/versions/vX.X.md с описанием патча

❓ Часто задаваемые вопросы

Q: Как мне начать разработку нового патча?
A: Откройте СТРУКТУРА-АРТЕЛЬ.md и прочитайте его полностью. Это главный документ проекта. Проверьте что ваши идеи не противоречат регламенту.
Q: Что делать если мой патч противоречит СТРУКТУРЕ?
A: ОСТАНОВИТЕСЬ! Первым делом обновите СТРУКТУРУ-АРТЕЛЬ.md, обсудите изменения, потом разрабатывайте патч.
Q: Как редактировать СТРУКТУРУ-АРТЕЛЬ?
A: Нажмите кнопку "✏️ Редактировать" на этой странице. Откроется редактор Markdown. После сохранения файл обновится.
Q: Кто может менять СТРУКТУРУ-АРТЕЛЬ.md?
A: Это совместное решение между вами и Claude. Обсудите перед изменениями, докумен­тируйте почему нужна правка.
Q: Где хранятся все файлы документации?
A: В папке docs/:
СТРУКТУРА-АРТЕЛЬ.md — главный регламент
История.md — навигация по версиям
versions/ — описание каждого патча (vX.X.md)
