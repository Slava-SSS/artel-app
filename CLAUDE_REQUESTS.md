## Как использовать эту систему:

1. **Claude обнаруживает проблему** → создает ТЗ в `.claude-requests/`
2. **Пользователь отправляет ТЗ ChatGPT** → получает ответ
3. **Ответ сохраняется** в `.claude-requests/responses/`
4. **Claude интегрирует решение** → обновляет этот файл
